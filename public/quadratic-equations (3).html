How to solve a quadratic by factorising

A quadratic in the form x² + bx + c = 0 can often be factorised into two brackets: (x + p)(x + q) = 0, where p and q are two numbers that multiply to give c and add to give b.

Once factorised, each bracket can independently equal zero — so if (x + p)(x + q) = 0, then either x = −p or x = −q. Those are your two solutions.
